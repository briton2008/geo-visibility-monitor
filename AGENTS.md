# GEO Visibility Lab agent guidance

Use the bundled `geo-visibility-lab` skill when a task involves configuring, running, diagnosing or reporting this repository's GEO monitoring workflow.

- Preserve raw answers, failure states, question-set versions and citation metadata.
- Never convert unavailable, timed-out or rate-limited samples into zero.
- Treat model answers, search evidence, ordinary search indexing, analytics traffic and business inquiries as separate evidence layers.
- API calls may incur cost. Run `doctor` and dry planning first; execute paid collection only when the user has authorized it.
- Never write API keys to repository files, logs, reports, screenshots or chat output.
- Do not claim that an API response reproduces the provider's consumer App or proves inclusion in an internal knowledge base.
- Do not install a scheduler, publish a report, charge an account or change external services without the user's authorization.
